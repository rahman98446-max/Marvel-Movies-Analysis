# Marvel-Movies-Analysis
This project analyzes data from the Marvel Cinematic Universe (MCU) to uncover interesting trends about movie performance, audience reception, and financial success. Using Python for data cleaning and analysis and Power BI for visualization, the project transforms raw movie data into meaningful insights through interactive dashboards.

The analysis covers different aspects of Marvel movies, including box office performance, ratings, budgets, profitability, release trends, and audience popularity, helping users better understand how the MCU has evolved over the years.
